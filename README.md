# Practice 6: Python File Handling and Built-in Functions

This repository contains practical examples for Python file and directory management, as well as core built-in functions.

## Structure
- `file_handling/`: Scripts for creating, reading, appending, copying, and deleting files.
- `directory_management/`: Scripts for creating nested directories, checking paths, listing contents, and moving files.
- `builtin_functions/`: Demonstrations of `map`, `filter`, `reduce`, `enumerate`, `zip`, and type conversions.
